# Changelog

## 0.1.0 — 2026-10-05
First release. Seven skills for an entry-level job search, each complete in a plain chat with no tools:
cv-review, job-fit, cv-tailor, cover-letter, interview-prep, application-tracker, offer-compare.
An eval per skill with two graders (honesty counts double); tests that fail when a sentence carrying one of the plugin's promises is removed.
Reviewed before release: the rule now also forbids upgrading what the user did, inventing an outcome, a motivation, a learning plan or any part of a STAR story; care with personal details and web search; no merged or percentage fit scores; pay rules for 13th salaries, hourly and net figures.
